# 乐谱工程数据格式（score.json）版本 1

一份 score.json 就是一首曲子的全部转录结果。播放器由它生成；修订时只改它，再重新生成播放器。

## 1. 时值单位：以全音符为 1 的分数

所有拍位（pos）和时值（dur）都写成分数字符串，以**全音符 = 1** 计：

| 写法 | 含义 |
|---|---|
| `"1/4"` | 四分音符 |
| `"1/8"` | 八分音符 |
| `"1/16"` | 十六分音符 |
| `"3/8"` | 附点四分音符 |
| `"3/16"` | 附点八分音符 |
| `"1/12"` | 八分音符三连音中的一个（3 个合计 1/4） |
| `"1/6"` | 四分音符三连音中的一个（3 个合计 1/2） |
| `"1/2"`、`"1"` | 二分音符、全音符 |

脚本用精确分数计算，不会出现小数误差累计。拍号 `"4/4"` 的小节总长为 1，`"3/4"` 为 3/4，`"2/4"` 为 1/2。

## 2. 顶层结构

```json
{
  "format": "guitar-score",
  "version": 1,
  "meta": {
    "title": "曲名",
    "source": "来源说明，如：某某曲谱图片第1页",
    "transcriber": "谁转录、何时",
    "kind": "transcription"
  },
  "tuning": {"6": "E2", "5": "A2", "4": "D3", "3": "G3", "2": "B3", "1": "E4"},
  "capo": 0,
  "key": "C",
  "tempo": [{"bar": 1, "bpm": 67}],
  "parts": [ ... ],
  "shapes": { ... },
  "bars": [ ... ],
  "playOrder": null,
  "sections": [ ... ],
  "assumptions": [ ... ],
  "issues": [ ... ],
  "edits": [ ... ]
}
```

- `meta.kind`：`"transcription"` 表示真实谱面转录；`"selftest"` 表示自编测试谱。
- `tuning`：各弦空弦音高，1 弦最细。省略时为标准调弦。
- `capo`：变调夹品位。六线谱品位数字和和弦图都按“相对变调夹”理解，播放时整体升高 capo 个半音。
- `key`：简谱的 1 = 哪个音（实际发音，不受 capo 影响），如 `"C"`、`"bE"`、`"#F"`。简谱 1 默认落在 C4 所在八度。
- `tempo`：速度表，每项在某小节开头生效，bpm 以四分音符计。第一项必须是第 1 小节。
- `playOrder`：一般留 `null`，由反复记号自动展开。遇到 D.S.、Coda 等复杂跳转时，直接写播放顺序，例如 `[[1,8],[1,6],[9,12]]`（每项为起止小节号，含两端）。
- `sections`：可省略。播放器上的段落按钮，点一下就选中这一段并循环。每项写 `{"name": "副歌", "from": 9, "to": 16}`；有反复的，加 `"pass": 2` 表示从第几遍的 `from` 小节开始（默认第 1 遍），到其后第一次出现的 `to` 小节为止。段落名照原谱写；原谱没有标段落名的，用“第1遍”“第二房”这类按结构起的名称，不要自己定“主歌”“副歌”。
- `assumptions`：原谱缺失、按假设处理的信息，每条一句话，例如 `"原谱未标调弦，按标准调弦处理"`。

## 3. 声部 parts

```json
"parts": [
  {"id": "g1", "name": "吉他 I（伴奏）", "kind": "guitar"},
  {"id": "g2", "name": "吉他 II（主音）", "kind": "guitar"},
  {"id": "vox", "name": "人声旋律", "kind": "melody"}
]
```

`kind` 只有两种：`guitar`（六线谱、叉号、扫弦）和 `melody`（简谱或音名）。

## 4. 和弦指型 shapes

和弦名不能代替原图指型，所以每个指型按原图和弦图逐弦记录：

```json
"shapes": {
  "C":     {"name": "C",  "frets": {"6": "x", "5": 3, "4": 2, "3": 0, "2": 1, "1": 0}},
  "Cmaj7": {"name": "C大七", "frets": {"6": "x", "5": 3, "4": 2, "3": 0, "2": 0, "1": 0}, "from": "原图和弦图"}
}
```

- `frets` 六根弦都要写：数字为品位，`"x"` 为该弦不弹。
- 键名（如 `"Cmaj7"`）是本文件内的引用名，`name` 是页面上显示的名字。
- 同名和弦按法不同（如低把位 F 与高把位 F），要用不同键名，例如 `"F"` 和 `"F_8"`。
- `from` 可选，用于说明指型依据；原图没画和弦图、按常用指型推定的，写 `"推定：常用指型"`。

## 5. 小节 bars

```json
{
  "n": 1,
  "time": "4/4",
  "partial": null,
  "chords": [{"pos": "0", "shape": "C"}, {"pos": "1/2", "shape": "Am"}],
  "repeatStart": false,
  "repeatEnd": 0,
  "ending": null,
  "img": {"page": 0, "box": [120, 340, 260, 180]},
  "status": "draft",
  "voices": { "g1": [ ... ], "vox": [ ... ] }
}
```

- `n`：小节号，从 1 起，连续递增。原谱开头的弱起小节不编号、下一小节才是第 1 小节的，弱起小节写 `"n": 0` 并写 `partial`，这样小节号与原谱一致；此时 `tempo` 的第一项可写第 0 小节。
- `time`：拍号。只在变化时必须写，省略则沿用上一小节。
- `partial`：弱起或不完整小节的实际长度，如 `"1/4"`。只有写了 partial，声部总长才允许不等于拍号长度。
- `chords`：本小节内和弦（指型）的生效位置。没写时沿用上一个和弦。
- `repeatStart`：本小节开头有反复开始记号 `|:`。
- `repeatEnd`：本小节结尾有反复结束记号 `:|`，数值为总共演奏几遍（通常为 2）；0 表示没有。
- `ending`：第几房（几号结尾），如 `[1]`、`[2]`、`[1,2]`。连续几个小节同属一房时，每个小节都要写。
- `img`：本小节在原图上的位置（像素，`[左, 上, 宽, 高]`，page 为第几张图，从 0 起）。没有准确坐标就不写，播放器不会伪造高亮。
- `status`：`"draft"`（AI 初转）、`"doubt"`（有疑点）、`"confirmed"`（已人工确认）。重新识别时不得覆盖 `confirmed` 小节，除非用户同意。
- `voices`：每个声部一串事件，按时间顺序首尾相接；每个出现的声部，总长都必须等于小节长度。本小节不演奏的声部可以省略（视为整小节休止）。

## 6. 事件

每个事件必须有 `dur`。`pos` 可写可不写；写了就必须等于前面事件时值之和，用于交叉核对。

### 6.1 吉他声部

**单音或和音（六线谱品位）**

```json
{"dur": "1/8", "notes": [{"s": 5, "f": 3}, {"s": 2, "f": 1}]}
```

`s` 为弦号（1–6），`f` 为品位（0–24）。附加可选项：

- `"x": true`：该弦闷音（谱面上画在弦上的 x），发短促的打击声。
- `"tie": true`：延音线连到的后一个音，不重新拨弦，只延长前一个音。
- `"tech": "h"`：技巧标记（h 击弦、p 勾弦、sl 滑音、b 推弦、v 揉弦）。**本版只记录，不演奏**，照普通音发声。

**按当前指型拨弦（和弦图配叉号的分解和弦谱）**

```json
{"dur": "1/8", "shape": [5]}
{"dur": "1/8", "shape": [3, 2, 1]}
```

列出要拨的弦号，品位从当前生效的指型里取。叉号本身不代表闷音；它是“按住当前和弦，弹这根弦”。指型里该弦为 `"x"` 时报错。

**扫弦**

```json
{"dur": "1/8", "strum": "down"}
{"dur": "1/16", "strum": "up", "strings": [3, 2, 1]}
{"dur": "1/8", "strum": "down", "mute": true}
```

- `strum`：`"down"` 下扫（6 弦往 1 弦，箭头向上画的谱面要看图例，转录时以实际方向为准）、`"up"` 上扫。
- `strings`：可选，只扫部分弦；省略时扫当前指型里所有可弹的弦。
- `"mute": true`：闷音扫弦（切音），发短促的打击声。

**休止**

```json
{"dur": "1/4", "rest": true}
```

可选 `"accent": true`（重音）和 `"vel": 0.3–1.0`（力度，默认 0.8）适用于所有发声事件。

### 6.2 旋律声部

```json
{"dur": "1/4", "jp": "5"}
{"dur": "1/8", "jp": "1'"}
{"dur": "3/8", "jp": "#4,"}
{"dur": "1/4", "pitch": "G4"}
{"dur": "1/4", "rest": true}
{"dur": "1/4", "jp": "5", "tie": true}
```

- `jp`：简谱音级 1–7，前面可加 `#` 或 `b`；后面加 `'` 表示高八度（上加点），加 `,` 表示低八度（下加点），可叠加。
- `pitch`：也可直接写音名，如 `"G4"`、`"F#3"`、`"Bb4"`。
- `"tie": true`：与前一个音连成一个音。
- `lyric`：可选，该音对应的歌词字，只用于显示。谱上有多段歌词（同一行音符下印两三行字）时写列表，第 n 项是第 n 段，没有字的段写空串，如 `"lyric": ["我", "送"]`。播放器把几段上下排开；反复演奏时，第几遍就把第几段当作当前歌词。

## 7. 疑点 issues

```json
"issues": [
  {
    "id": "Q1",
    "bar": 12,
    "part": "g2",
    "where": "第12小节吉他II第3个音",
    "desc": "品位数字模糊，可能是 8 或 6",
    "candidates": ["8", "6"],
    "adopted": "8",
    "level": "key",
    "status": "open"
  }
]
```

- `level`：`"key"` 关键（影响音高、节奏或结构）或 `"minor"` 次要。
- `status`：`"open"` 未解决，`"resolved"` 已由用户确认。
- 存在 `level` 为 `key` 且 `status` 为 `open` 的疑点时，播放器标题旁显示“待校对试听版”。

- `leapOk`：可选，小节号列表。用户已确认某处旋律大跳无误时，在这条疑点里写上涉及的小节号，疑点改为 `resolved` 后，`check` 不再把这几个小节之间的大跳列为待核对。

## 8. 用户修订记录 edits

```json
"edits": [
  {"date": "2026-10-29", "bar": 5, "desc": "第5小节第3弦改为2品", "by": "用户"}
]
```

每次按用户意见修改数据，都追加一条，并把该小节的 `status` 改为 `confirmed`。

## 9. 反复展开规则

1. 从第 1 小节开始顺序演奏。
2. 遇到 `repeatEnd: N` 的小节，若本段尚未演奏满 N 遍，回到最近的 `repeatStart` 小节（没有则回到第 1 小节），遍数加 1。
3. 带 `ending` 的小节，只在当前遍数包含在列表中时演奏，否则跳过。
4. 展开超过 5000 个小节即判定结构有误并报错，不会死循环。

播放器里，每个“播放位置”显示为“第 n 小节（第 p 遍）”，选段按播放位置选，起止两端都包含在内。
