# song.json 格式与读谱规则

转录前通读一遍。格式样板见 `examples/demo.song.json`。

## 一、整体结构

~~~json
{
 "title": "曲名",
 "credits": ["某某 唱", "某某 编", "选调 C，原调 E♭"],
 "bpm": 100,
 "beats": 4,
 "tonicMidi": 60,
 "pickupRest": 3,
 "numberOffset": 0,
 "tuning": {"1":64,"2":59,"3":55,"4":50,"5":45,"6":40},
 "shapes": { "Am": {"1":0,"2":1,"3":2,"4":2,"5":0,"6":0} },
 "sequence": [[0,8],[9,23],[24,32],[9,23],[33,60]],
 "sections": [["前奏",[0,8]],["主歌",[9,16]]],
 "measures": [ {"n":0,"ch":[["Am",0]],"acc":["","","","","","","1=0","1=1"],"mel":"0:3 3:.5 4:.5"} ]
}
~~~

| 字段 | 含义 |
|---|---|
| `title`、`credits` | 页面顶栏显示的曲名和几条说明文字（演唱、编配、调） |
| `bpm` | 谱上标的拍速，作为默认速度 |
| `beats` | 每小节拍数，4/4 填 4 |
| `tonicMidi` | 简谱"1"对应的 MIDI 音高。按**选调**（实际按的指型）填：1=C 填 60，1=G 填 55 或 67，1=D 填 62，以此类推。用下面"互相校验"的办法确定八度 |
| `capo` | 可选。页面打开时变调夹的默认品位（0–5），不写即不夹。用户在页面上可改 |
| `lang` | 可选。界面默认语言：`zh-CN`、`zh-TW`、`en`、`ja`、`ko`、`es`、`fr`、`de`、`pt`，不写则跟随浏览器。`sections` 的名称照常用简体中文写（前奏、主歌、副歌、间奏、结尾副歌、尾奏、桥段），页面会自动翻译这几个常见名称，其他名称原样显示 |
| `i18n` | 可选。曲名和署名的译法：`{"en":{"title":"…","credits":["…"],"gist":{"主歌":"一句概述","副歌":"…"}}, "ja":{…}}`；`gist` 可选，键是 `sections` 里的段落名，值是用该语言写的一句段落大意，语言代码同 `lang`。没写的语言显示 `title`、`credits` 原文 |
| `labels` | 可选。谱面图片上的段落文字，用于换语言时在原位置盖上译文：`[{"s":行号(从0起),"x":左,"y":上,"w":宽,"h":高,"text":"前奏"}]`，坐标是原图像素，框要刚好包住原字。原字底色不是白色时加 `"bg":"#FCE9E9"`。`text` 用简体中文的常见段落名（前奏、主歌、副歌、间奏、结尾、结尾副歌、尾奏、桥段），页面自带这些词的译文 |
| `jianpuRows` | 可选。每行谱简谱所在的纵向位置，页面据此在使用者的浏览器里自动识别旋律：`[{"s":行号,"y":上边,"h":高}]`，原图像素。上边要包住连音弧线和高音点；下边要包住下划线和低音点，下面有歌词时切在第一行歌词的中间。给了它且各小节 `mel` 为空（或全是休止）时，页面自动识谱；`mel` 里写了旋律则以 `mel` 为准 |
| `lyricRows` | 可选。谱面上每一行歌词的位置（只记位置）：`[{"s":行号,"y":上边,"h":高}]`，原图像素；一行谱有两行歌词就写两项。`geometry.json` 里每行谱的 `textBands` 列出了谱线下方各文字横带的上下边，可作参考。页面据此为每个小节生成一个可填写的译文格 |
| `lyricPhrases` | 可选。按**演唱顺序**列出每个乐句占用的格子，供“整段粘贴、按句填入”用：`[{"r":该行谱里第几行歌词(从0起),"m":[小节下标…],"blank":["8.0"]}]`。`m` 是这一句歌词所在的小节；句首的弱起字落在上一小节末尾时不用管（上一句的格子会遮住它），若那个小节不属于任何乐句，就把它写进 `blank`（格式“小节下标.歌词行号”）。反复演唱的段落按唱的次数重复列出 |
| `pickupRest` | 弱起：第 0 小节开头休止几拍。没有弱起填 0 |
| `numberOffset` | 小节下标与谱上小节号的差。有弱起小节时下标 0 是弱起、下标 1 就是第 1 小节，填 0；没有弱起时下标 0 是第 1 小节，填 1 |
| `tuning` | 各弦空弦的 MIDI 音高，标准调弦如上。1 是最细的弦 |
| `shapes` | 用到的每个和弦的指型：各弦品位，不弹的弦填 0 |
| `sequence` | 全曲实际演奏顺序，由若干 `[起,止]` 段（小节下标，含两端）依次拼成，用来表达反复和房子 |
| `sections` | 循环按钮：名称和 `[起,止]` 下标 |
| `measures` | 每小节一项，顺序与 `geometry.json` 的 `measures` 一一对应。`n` 只是给人看的序号，可写可不写 |

## 二、每小节的三样东西

### 1. `ch` 和弦

`[["和弦名", 起始拍], ...]`。整小节一个和弦写 `[["Am",0]]`；前两拍 F 后两拍 E 写 `[["F",0],["E",2]]`。和弦名必须在 `shapes` 里有。弱起小节没标和弦时，填它后面那个小节的和弦。

### 2. `acc` 伴奏（六线谱）

长度为 `beats×2` 的数组，每格一个八分位，空拍填 `""`。每格的写法：

- `"3"`：拨 3 弦，品位取当前和弦指型（谱上画的是 **x**）
- `"2=3"`：拨 2 弦 3 品（谱上写的是**数字**，数字就是品位，`2=0` 是空弦）
- `"1,5"`：同时拨 1 弦和 5 弦，逗号连接，可混用：`"1=1,4"`

不在八分位上的音（十六分音符、琶音）另写在 `x` 里：`"x": [[3.5,"2=3"],[3.75,"2"]]`，第一个数是小节内的拍位（从 0 起，3.5 即第四拍后半）。此时 `acc` 里对应的格子留空或只放落在八分位上的那个音，不要重复。

扫弦或琶音和弦：用 `x` 把各弦错开一点依次写出，例如 `[[0,"5"],[0.07,"4"],[0.14,"3"],[0.21,"2"],[0.28,"1"]]`。

### 3. `mel` 旋律（简谱）

用空格分开的若干 `音:时值`，时值以拍为单位，合计应等于 `beats`：

- 音：`1`–`7`；低音点在后面加 `,`（`6,`），高音点加 `'`（`1'`），两个点就写两个；升降号写在前面（`#4`、`b7`）；休止写 `0`
- 时值：四分音符 `1`，八分 `.5`，十六分 `.25`，附点四分 `1.5`，附点八分 `.75`，二分 `2`；简谱里一个音后面每多一条"–"加 1 拍

例：`5· 5 5 4 3 2`（附点四分、八分、四个八分）写成 `"5:1.5 5:.5 5:.5 4:.5 3:.5 2:.5"`。

## 三、读谱规则

**六线谱**

- 六条线从上到下是 1 弦到 6 弦
- x 表示按当前和弦指型弹这根弦；数字表示品位。数字多出现在 1、2 弦上（带旋律的音）
- 符干下面连一条横线的一组是八分音符，两条横线是十六分音符；一小节通常正好 8 个八分位
- `report.txt` 每小节一行，形如 `16:1,5 | 29:4 | 42:3 …`，竖线分隔的每段是一个拍位，冒号后是有记号的弦号。带 `?` 的疑似数字，要看放大图确认是几
- `report.txt` 可能混入的假记号：连音弧线、反复记号的两个点、房子的"1." "2."字样、灰色的连音延续音符。对照放大图剔除

**简谱**

- 数字下面一条线是八分音符，两条线是十六分音符；数字后的圆点是附点
- 数字下方的点是低八度，上方的点是高八度。低分辨率下点很小，容易漏，要放大看
- 弧线连着两个相同的音是连音线（后一个常印成灰色）：合并成一个音，时值相加
- 数字左上角的小数字是倚音，略去
- 歌词有两行的段落是反复段，两遍歌词不同，音相同

**反复与房子**

- `|:` 到 `:|` 之间反复。有"1."房子时，第一遍弹完 1 房子后回到 `|:`；第二遍弹到 1 房子前直接跳进"2."房子
- 写成 `sequence`：`[[开头到反复段前],[反复段到1房子前],[1房子],[反复段到1房子前],[2房子到结尾]]`
- D.S.、D.C.、Coda 同理，按实际演奏顺序拆成段

**段落**

- 谱上标的"前奏、主歌、副歌、间奏、尾奏"等就是 `sections` 的来源；没标的按歌词和和弦进行自行划分
- 段落的起止尽量落在整小节上；弱起音留在前一小节不必纠结

## 四、互相校验（很重要）

1. **用旋律定八度**：前奏里吉他 1、2 弦上的数字音就是简谱旋律。比如 1 弦 0 品是 E4（MIDI 64），若简谱此处写"3"且没有高低音点，则"1"=C4，`tonicMidi` 填 60
2. **用旋律查伴奏**：纯器乐段（前奏、间奏、尾奏）里，每个旋律音都应能在同一拍位的伴奏里找到同音高的音。找不到就是有一边读错了
3. **用和弦查伴奏**：x 所在的弦若在该和弦指型里是"不弹"的弦（如 Am 的 6 弦），多半是弦号数错了一根
4. **用时值查旋律**：每小节时值合计必须等于 `beats`，`build.py` 会报出不等的小节

## 五、容易踩的坑

- **弱起小节**：下标 0 只有最后一两个音，前面是休止。`acc` 照样写满 8 格（前面填空），`mel` 以 `0:休止拍数` 开头，并设置 `pickupRest`
- **每行第一小节**：左边有 TAB 字样、拍号、小节号，`detect.py` 会忽略这段宽度；如果第一个音离左边很近被误删，调小 `--clef`
- **一小节两个和弦**：x 的品位要按**所在那半小节**的和弦取，所以 `ch` 里的起始拍要写对
- **跨小节连音**：把总时值记在前一小节（合计会超过 `beats`，`build.py` 只提示不报错），后一小节开头补等长的休止
- **整小节延音**：简谱是 `6 - - -` 且下一小节用连线延续的，前一小节写 `6,:8`，后一小节写 `0:4`
- **同一和弦不同把位**：谱上和弦图与常见指型不同时，以谱上和弦图为准填 `shapes`
- **Dm 与 Dm7 这类相近和弦**：分别建指型，不要合并

## 六、geometry.json 需要手改时

每个小节：`{"s": 所在行, "l": 左小节线x, "r": 右小节线x, "x1": 第一个八分位的x, "d": 相邻八分位间距}`，单位是原图像素。光标位置 = `x1 + 拍位×2×d`。

- 小节以休止开头，或音符很少：`x1` 可能被定到了第一个出现的音上，改成 `l + 同行其他小节的首音偏移`（常见约 16）
- 音符排得不均匀的小节：选一个让首尾两个音都大致对上的 `d`
- 末小节只有一个长音或一个琶音：`d` 取 `(r - x1) / (beats×2)` 左右，让光标匀速走完
- 弱起小节不用手改，`build.py` 会按 `pickupRest` 自动回推起点
